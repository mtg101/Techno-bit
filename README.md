Messing about with Micro:bits https://microbit.org/ to make tracker music, like back in the good old Amiga days. But with each Micro:bit playing a single track, and a conductor broadcasting radio signals to play patterns.

AI has been used in areas of this project, not for the code (beyond conversing with LLMs for advice), but importantly for some of the musical and visual assets. I'm here to be creative with the code, and I've never meed able to make a good tracker tune :( Others are free to use this code or the idea to make their own music :)
